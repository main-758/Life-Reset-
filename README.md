# Life Reset

A functional browser/PWA build for GitHub Pages.

## Included
- Dashboard and next-action focus
- Brain Dump organizer
- Today task planner
- Money Reset
- Career tracker
- Goals
- Progress/history
- Calendar
- Plus/paywall UI
- Local persistence
- Export data
- Responsive mobile UI
- PWA manifest + service worker

## Deploy
Publish the repository root with GitHub Pages. The entry point is `index.html`.

## Production note
The browser build intentionally does not expose a secret AI key or pretend to have real subscriptions. A production paid product needs a secure backend for accounts, payments, and any server-side AI calls.
